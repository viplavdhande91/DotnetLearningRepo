# .NET Dependency Injection — Service Registration

Service registration defines **how dependencies are added to the DI container** so that the framework can create and inject them when needed.

Services are registered in **IServiceCollection** during application startup.

Example:

```csharp
var builder = Host.CreateApplicationBuilder(args);

builder.Services.AddSingleton<IMessageWriter, MessageWriter>();

var host = builder.Build();
host.Run();
````

---

# Register Groups of Services

.NET frameworks often register **multiple related services using a single extension method**.

Convention:

```
Add{GroupName}()
```

Example:

```csharp
builder.Services.AddOptions();
```

This registers all services required for the **Options pattern**.

Example usage:

```csharp
public class MyOptions
{
    public string Name { get; set; }
}

builder.Services.Configure<MyOptions>(options =>
{
    options.Name = "Viplav";
});
```

Using the options service:

```csharp
public class MyService
{
    private readonly IOptions<MyOptions> _options;

    public MyService(IOptions<MyOptions> options)
    {
        _options = options;
    }

    public void Print()
    {
        Console.WriteLine(_options.Value.Name);
    }
}
```

# Framework-Provided Services

When using builder patterns, .NET automatically registers many services.

Examples of builders:

* `Host.CreateDefaultBuilder()`
* `Host.CreateApplicationBuilder()`
* `WebApplication.CreateBuilder()`
* `WebHost.CreateDefaultBuilder()`

Example:

```csharp
var builder = WebApplication.CreateBuilder(args);

var app = builder.Build();

app.MapGet("/", (ILogger<Program> logger) =>
{
    logger.LogInformation("Hello from logger");
    return "Hello World";
});

app.Run();
```

Here `ILogger<T>` is automatically provided by the framework.

# Service Registration Methods

.NET provides several methods to register services.

## 1. Register Service and Implementation

Most common approach.

```csharp
builder.Services.AddSingleton<IMessageWriter, MessageWriter>();
```

Example implementation:

```csharp
public interface IMessageWriter
{
    void Write(string message);
}

public class MessageWriter : IMessageWriter
{
    public void Write(string message)
    {
        Console.WriteLine(message);
    }
}
```

Using the service:

```csharp
public class Worker
{
    private readonly IMessageWriter _writer;

    public Worker(IMessageWriter writer)
    {
        _writer = writer;
    }

    public void DoWork()
    {
        _writer.Write("Worker started");
    }
}
```

---

## 2. Register Using Factory Method

Used when object creation needs custom logic.

```csharp
builder.Services.AddSingleton<IMessageWriter>(sp =>
{
    return new MessageWriter();
});
```

Example with constructor parameter:

```csharp
public class MessageWriter : IMessageWriter
{
    private readonly int _id;

    public MessageWriter(int id)
    {
        _id = id;
    }

    public void Write(string message)
    {
        Console.WriteLine($"[{_id}] {message}");
    }
}
```

Registration:

```csharp
builder.Services.AddSingleton<IMessageWriter>(sp =>
{
    return new MessageWriter(99);
});
```

---

## 3. Register Implementation Only

```csharp
builder.Services.AddSingleton<MessageWriter>();
```

Equivalent to:

```csharp
builder.Services.AddSingleton<MessageWriter, MessageWriter>();
```

Example usage:

```csharp
public class Worker
{
    private readonly MessageWriter _writer;

    public Worker(MessageWriter writer)
    {
        _writer = writer;
    }

    public void Run()
    {
        _writer.Write("Running worker");
    }
}
```

---

## 4. Register Existing Instance

Example:

```csharp
var writer = new MessageWriter();

builder.Services.AddSingleton<IMessageWriter>(writer);
```

Example usage:

```csharp
public class Worker
{
    private readonly IMessageWriter _writer;

    public Worker(IMessageWriter writer)
    {
        _writer = writer;
    }

    public void Run()
    {
        _writer.Write("Instance example");
    }
}
```

# Register Multiple Implementations

You can register multiple implementations of the same service.

Example:

```csharp
builder.Services.AddSingleton<IMessageWriter, ConsoleMessageWriter>();
builder.Services.AddSingleton<IMessageWriter, LoggingMessageWriter>();
```

Implementations:

```csharp
public class ConsoleMessageWriter : IMessageWriter
{
    public void Write(string message)
    {
        Console.WriteLine(message);
    }
}

public class LoggingMessageWriter : IMessageWriter
{
    public void Write(string message)
    {
        Console.WriteLine($"LOG: {message}");
    }
}
```

Service consuming them:

```csharp
public class ExampleService
{
    public ExampleService(
        IMessageWriter writer,
        IEnumerable<IMessageWriter> writers)
    {
        writer.Write("Single writer resolved");

        foreach (var w in writers)
        {
            w.Write("Multiple writer resolved");
        }
    }
}
```

Behavior:

* `IMessageWriter` resolves **last registered implementation**
* `IEnumerable<IMessageWriter>` resolves **all implementations**

# TryAdd Methods

Registers a service **only if it has not already been registered**.

Example:

```csharp
builder.Services.AddSingleton<IMessageWriter, ConsoleMessageWriter>();

builder.Services.TryAddSingleton<IMessageWriter, LoggingMessageWriter>();
```

Result:

Only `ConsoleMessageWriter` is used because it was already registered.

Example service:

```csharp
public class ExampleService
{
    public ExampleService(IMessageWriter writer)
    {
        writer.Write("Using registered writer");
    }
}
```

---

# TryAddEnumerable

Registers service only if the **same implementation type is not already registered**.

Example:

```csharp
services.TryAddEnumerable(
    ServiceDescriptor.Singleton<IMessageWriter, ConsoleMessageWriter>()
);

services.TryAddEnumerable(
    ServiceDescriptor.Singleton<IMessageWriter, ConsoleMessageWriter>()
);
```

Only one instance of `ConsoleMessageWriter` will be registered.

# Register Service Using ServiceDescriptor

`IServiceCollection` internally stores services as **ServiceDescriptor objects**.

Example:

```csharp
string secretKey = "abc123";

var descriptor = new ServiceDescriptor(
    typeof(IMessageWriter),
    sp => new MessageWriter(),
    ServiceLifetime.Transient
);

services.Add(descriptor);
```

Equivalent to:

```csharp
services.AddTransient<IMessageWriter, MessageWriter>();
```

# Summary

Service registration tells the DI container:

* What service type to resolve
* Which implementation to use
* The lifetime of the service

Common registration methods:

```
AddSingleton
AddScoped
AddTransient
TryAdd
TryAddEnumerable
```
